-- Cómo abrir el proyecto en Netbeans---
1.- Instalar NetBeans 25 y JDK 20 (tal y como pide el enunciado)
2.- Clonar el Repositorio
3.- Darle a File -> New Project -> HTML5/JavaScript -> HTML5/JS Application with Existing Sources
<img width="716" height="491" alt="image" src="https://github.com/user-attachments/assets/4d8a042e-10d9-4a93-bc1a-3603997d3c56" />

4.- En Site Root darle a Browse y poner la ruta C:\......WEB\Parte 2\WEB
<img width="521" height="212" alt="image" src="https://github.com/user-attachments/assets/b3f52008-7e31-468b-986e-22dd7056426b" />

5.- En la barra superior, darle al icono de Chrome y seleccionar la Opción Google Chrome (o el navegador que uséis). Si usais Chrome elegid solo la que dice Chrome (no la de Chrome with NetBeans Connector porque a mí no me ha funcionado)
<img width="1069" height="350" alt="image" src="https://github.com/user-attachments/assets/69c78d02-87fb-45ce-b1ea-cd8fd6d94b97" />

6.- Una vez hecho esto, darle al icono de Run y se te abrirá la página de Registro/Iniciar Sesión en el navegador. Una vez registrado/iniciado sesión podrás navegar por la aplicación tal y como se podía en la PL1
